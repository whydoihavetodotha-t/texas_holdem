# 德州撲克 —— 玩家說明

你一個人對上幾個電腦玩家。有標準德州撲克和「同色牌型」變形兩種玩法,現金桌和
錦標賽兩種賽制,還可以加玩魷魚遊戲。每一手的洗牌都能自己驗證,確定沒有作弊。

## 一、快速上手

### 登入

打開網址會看到:

```
  [1] 登入   [2] 註冊新帳號   [e] 離開   (直接按 Enter = 登入)
  >
```

* **第一次來**:按 `2` 註冊。取一個帳號名稱(最多 20 個字,不能有 `< > : " / \ | ? *`,
  也不能只用單獨的 `e`、`h`、`b`),密碼輸入兩次。名稱那一題輸入 `e` 取消。
* **之後**:按 `1`(或直接按 Enter),輸入帳號和密碼。
* 輸入密碼時畫面不會顯示,這是正常的。
* 帳號或密碼打錯只會說「帳號或密碼錯誤」,等 1 秒就能再試,不會被鎖。
* **新帳號會直接送你 100,000 籌碼。**
* 同一個帳號同時只能在一個地方登入。

### 主選單

登入後會先打聲招呼,然後是主選單:

```
  阿明 的主選單  (任何地方輸入 h 回到這裡)
    [1] 開始牌局   ← 預設
    [2] 牌譜復盤       重看打過的手牌、篩選、AI 復盤紀錄、驗證洗牌
    [3] 我的帳本       每一場的增減、查某一天的收益
    [4] 今日收益       今天開始的場次
    [5] 設定           牌局節奏、畫面顏色、10 的寫法
    [6] 修改密碼
    [7] 離開           登出,回到登入頁
```

打完一局也會回到這裡。選「離開」是**登出**,回到登入頁;在登入頁輸入 `e` 才會
真的結束。

### 到處都能用的按鍵

| 按鍵 | 在哪裡 | 作用 |
|---|---|---|
| Enter | 有預設值的題目 | 用括號裡的預設值(畫面上標 `← 預設` 或 `[Enter = …]`) |
| `h` | 牌局以外的任何地方 | 回到主選單。設定到一半的牌局整個取消,**不會扣任何錢** |
| `b` | 開局設定 | 回到上一題修改;在第一題按 `b` 回到主選單 |
| `e` | 登入頁 | 離開 |

牌局裡按 `h` 沒有作用 —— 要離開牌局用 `q`(見[離桌](#離桌))。

## 二、開一局

選「開始牌局」後依序回答幾題,每一題直接按 Enter 都是預設值:

1. **規則**:標準德州撲克 / 同色牌型變形(見[第四章](#同色牌型變形))
2. **賽制**:現金桌 / 錦標賽
3. 之後的題目看賽制:

| 賽制 | 接下來的題目 |
|---|---|
| 現金桌 | 要不要玩魷魚遊戲(要的話再問每條幾個大盲、數量 +N)→ 人數 → 大盲 → 買入 → 客戶端種子 |
| 錦標賽 | 升盲時間 → 人數 → 起始大盲 → 報名費 → 客戶端種子 |

| 設定 | 預設 |
|---|---|
| 人數 | 6 人(含你,2~10 人) |
| 升盲時間 | 2 分鐘(錦標賽) |
| 魷魚遊戲 | 不玩(現金桌) |
| 大盲 | 200。小盲自動是大盲的一半 |
| 買入 / 報名費 | 10,000,最多到你的帳戶餘額 |
| 客戶端種子 | 自動產生(想自己參與洗牌可以隨便打一串字) |

* 答錯了輸入 `b` 回上一題,原本的答案會是那一題的預設值。
* **問完所有題目、坐下的那一刻才從帳戶扣錢。** 在那之前按 `h` 回主選單,一毛都
  不會扣,買入金額已經輸入了也一樣。
* 你在牌桌上的名字就是帳號名稱。座位是隨機的。

### 籌碼從哪來

* 現金桌:買入多少,桌上就是多少;離桌時把桌上剩下的帶回帳戶。大盲最多是帳戶
  餘額的 1/20(至少要買得起 20 個大盲)。
* 錦標賽:帳戶只付報名費,桌上的是計分籌碼(一律 100 個起始大盲)。最後依名次分
  獎金。
* 現金桌輸光時,如果帳戶還有錢,會問你要不要**再買入同樣的金額**。
* **帳戶輸光(或被魷魚罰款扣成負的)就開不了新局**,也不能自己存錢。需要的話
  請找管理者幫忙。

### 設定

主選單的「設定」可以改:

| 設定 | 選項 |
|---|---|
| 牌局節奏 | 預設 / 加速(停頓減半)/ 放慢(停頓 1.5 倍)/ 全速(完全不停頓) |
| 畫面顏色 | 自動 / 開 / 關 |
| 10 的寫法 | 10(`10♦`)/ T(`T♦`) |

設定跟著帳號走,下次登入還在。

## 三、牌桌上

### 輪到你行動時

畫面會出現決策面板:盲注、公牌與底池、你的手牌與籌碼、要跟多少、每個對手的籌碼
與下注,以及你目前的牌型。所有籌碼都附上是幾個大盲。

| 指令 | 作用 |
|---|---|
| `c` | 過牌或跟注 |
| `f` | 蓋牌(不用付錢時自動改成過牌) |
| `r金額` | 加注到**總額**這麼多,例如 `r1600`(直接送出) |
| `r` | 加注到最低可加注的量 |
| `r/x` | 加注到 1/x 底池:`r/2` 半池、`r/3` 三分之一池、`r/0.5` 兩倍池 |
| `r*x` | 加注到 x 個大盲,例如 `r*3` |
| `a` | 全下 |
| `e` | 估算你目前的勝率(只用你看得到的資訊) |
| `q` | 離桌 |

**加注填的一律是加注後的總額。** `r`、`r/x`、`r*x`、`a` 算出金額後會先給你看一眼,
按 **Enter 送出**、其他鍵取消。算出來的金額不合法(低於最低加注、超過你的籌碼)時,
會問你要不要改成最低加注或全下,這時要按 **`y`** 才會送出,按 Enter 是取消。

### 全下之後跑幾次

大家都全下、還有公牌沒發時,可以提議剩下的公牌跑 1~3 次(Enter = 1 次;牌堆的牌不夠時
會告訴你最多能跑幾次)。跑一次
以上要所有還沒蓋牌的人都同意,電腦可能拒絕。跑幾次不影響期望值,只是讓輸贏的
波動變小;底池會平分成幾份,每一次各自比牌。

### 兩手牌之間

```
  Enter 下一手 / v 查核本手 / r AI 復盤 / q 離桌 >
```

| 指令 | 作用 |
|---|---|
| Enter | 發下一手(只有 Enter 會發牌,亂按不會) |
| `v` | 當場驗證這一手的洗牌(見[第六章](#六洗牌公平嗎)) |
| `r` | 請 AI 復盤剛打完的這一手(見[AI 復盤](#ai-復盤)) |
| `q` | 離桌 |

被淘汰、或輸光不再買入時,牌局結束前還有一次 `Enter 結束 / v 查核本手 / r AI 復盤`,
輸掉的那一手一樣能復盤。

### 離桌

按 `q` 都會先告訴你代價,再要你按 `y` 確認(Enter 是取消):

* 現金桌:把桌上的籌碼帶回帳戶。
* 錦標賽:算**棄權**,名次是當下的最後一名。
* 魷魚遊戲:手上有魷魚的會作廢;沒有魷魚的要當場付魷魚費。
* **下注途中按 `q`**:這一手直接蓋牌,已經推進底池的錢拿不回來,這手結束後離桌。

**關掉網頁或斷線不會讓你逃過輸贏。** 牌局會隨時存檔,下次登入時照最後的存檔結算:
打到一半斷線等於那一手蓋牌,沒有魷魚的照樣付魷魚費,錦標賽照當下的名次算。

## 四、玩法與賽制

### 同色牌型變形

把黑(♠♣)和紅(♥♦)當成兩種「顏色」。跟標準德撲只差兩點:

1. **多一種牌型「同色順」**:五張同色的連號(但不是同花),比順子大、比四條小。
2. **點數相同的對子,同色的贏異色的**,而且顏色比踢腳先比。例如一對 K 同色帶
   4 3 2,贏一對 K 異色帶 A Q J。

牌型由大到小:同花順 > **同色順** > 四條 > 葫蘆 > 同花 > 順子 > 三條 > 兩對 > 一對 >
高牌。畫面上的牌型會標出「同色」,例如 `一對 (K 同色，踢腳 A Q 9)`。

### 錦標賽

| | 現金桌 | 錦標賽 |
|---|---|---|
| 盲注 | 固定 | 每 N 分鐘升一級(升盲只在兩手牌之間) |
| 前注 | 無 | 大盲一個人付一份前注,金額 = 當前大盲 |
| 輸光 | 可以再買入 | 淘汰 |
| 帶回帳戶 | 桌上剩多少 | 依名次分獎金 |

獎金分配:2~3 人冠軍全拿;4~6 人 65% / 35%;7 人以上 50% / 30% / 20%。

### 魷魚遊戲(現金桌)

* **單獨贏下主池**就拿到一條魷魚(平分、只贏邊池都不算)。
* 每輪有「玩家數 + N」條,每條值幾個大盲在開局時設定。
* **只剩一個人沒有魷魚**時,他要為每一條魷魚付一份給主人;**魷魚發完**時,每一個
  沒有魷魚的人都要為每一條付一份。
* 罰款一律付足全額。你桌上的籌碼不夠時,不夠的部分直接從帳戶扣,帳戶可以扣成
  負的。
* 中途離場:有魷魚的魷魚作廢;沒有魷魚的當場為場上每一條付錢。
* 每一手的抬頭和決策面板都會寫誰手上有幾條。

## 五、打完之後

### 我的帳本

主選單的「我的帳本」:最近 20 場、全部場次、最近 N 場、某一天的收益。每一場列出
玩法、賽制、名次(錦標賽)、盲注、手數、買入、帶出與增減。「今日收益」只看今天
開始的場次(從晚上打到凌晨的那一場,算開始的那一天)。

### 牌譜復盤

每一手都會記下來,主選單的「牌譜復盤」可以:

| 選項 | 作用 |
|---|---|
| 場次列表 | 打過哪幾場,各場的編號與輸贏 |
| 看某一場的手牌 | 選場次(Enter = 最近一場,`0` = 所有場次),再篩選:全部 / 大輸贏 / 輸的 / 贏的 / 走到攤牌。看完可以直接打手數重現那一手 |
| 重現某一手 | `12` = 最近一場的第 12 手,`3-12` = 第 3 場的第 12 手 |
| AI 復盤紀錄 | 請 AI 復盤過的手牌;打代號(例如 `3-12`)直接重看 AI 當時說的話 |
| 搜尋 AI 復盤 | 在 AI 的評語和你的提問裡找關鍵字 |
| 手動驗證洗牌 | 自己貼上種子,重算整副牌 |

重現一手牌之後可以按 `v` 驗證那一手的洗牌、按 `r` 看 AI 復盤,Enter 返回。

### AI 復盤

請 AI 看你打的一手牌,逐街說哪裡打得好、哪裡有問題。兩手牌之間按 `r`,或在
牌譜復盤重現某一手後按 `r`。等待回覆大約 5~20 秒。

復盤完會出現:

```
  r 再復盤一次 / a 提問 / q 返回 >
```

* `r`:請 AI 從頭再看一遍(要按 `y` 確認)。
* `a`:打字問問題,例如「翻牌如果我過牌會怎樣?」。輸入 `q` 或直接按 Enter 回上一層。
* `q`:返回。

同一手再按 `r` 會把之前所有的評語和問答重印一遍,**重印不算次數**。

* **每個帳號每天有則數上限**(預設 5 則),復盤、再復盤、每一個提問各算一則。每則回覆後
  會顯示今天還剩幾則。
* 只回答跟德州撲克有關的問題(這一手牌、策略、規則都可以問)。無關的問題會直接告訴你
  「跟德州撲克無關」,**不算次數**。
* AI 只看得到**你當時看得到的東西**:你的底牌、公牌、每個人的動作、攤牌時亮出來的
  牌。對手蓋掉的牌不會給它看,所以它不會用「結果論」評你。
* AI 復盤適合找明顯的錯誤,但它不是 solver,它說的頻率和下注尺寸別當成標準答案。

## 六、洗牌公平嗎

每手牌開始前,畫面會先公布牌堆的**承諾值**(一串雜湊值),這時牌序就已經固定了;
這手牌結束後才公布洗牌用的種子。拿種子重算一次整副牌,如果雜湊值對得上,就證明
牌在你看到任何一張之前就洗好了,中途沒被動過。

* 兩手牌之間按 `v`:當場重算、比對,並印出完整的 52 張牌序,可以跟實際發出來的牌
  對照。
* 牌譜復盤重現某一手後按 `v`:驗證以前的任何一手。
* 你可以在開局時輸入自己的「客戶端種子」一起參與洗牌,莊家就無法單方面決定牌序。
* 電腦玩家拿不到牌堆,也看不到別人的底牌,只看得到跟你一樣的公開資訊。

## 七、常見問題

**畫面卡住不動?**
電腦出手、發牌之間本來就會停一下。嫌慢的話到「設定 → 牌局節奏」改成加速或全速。

**手機上怎麼打字?**
點一下畫面叫出鍵盤。每一題打完都要按 Enter(送出)。

**輸光了怎麼辦?**
現金桌可以再從帳戶買入。帳戶也沒錢的話就開不了新局,請找管理者。

**斷線了會怎樣?**
重新打開網址登入就好。上一場會照最後的存檔結算,登入時會告訴你結果。

**忘記密碼?**
請找管理者幫你重設一個新密碼,拿到之後登入,再到主選單的「修改密碼」改成你自己的。
記得舊密碼的話,直接在「修改密碼」改就好。
